# Student Task Tracker

## Project Overview

Student Task Tracker is a documentation project for a system that helps students record coursework tasks and monitor completion progress.

## Project Scope

The system will allow students to:

- Create and manage coursework tasks.
- Track task completion status.
- Organize academic activities.
- Monitor upcoming deadlines.

## Stakeholders

### Students
Students use the system to record assignments, track progress, and manage deadlines.

### Instructors
Instructors benefit from students having better organization and awareness of coursework requirements.

### Project Team
The project team uses documented requirements to understand future development needs.

## Initial Requirements

### Functional Requirements

1. Users should be able to create tasks.
2. Users should be able to update task status.
3. Users should be able to view incomplete and completed tasks.
4. Users should be able to manage task deadlines.

### Non-Functional Requirements

1. The system should be easy to use.
2. The system should store information reliably.
3. The system should provide quick access to task information.

## Future Improvements

Possible future features include:

- Notifications for upcoming deadlines.
- Priority levels for tasks.
- Progress reports.
- Mobile application support.
